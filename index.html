Pengaturan

Kelola akun dan preferensi tampilan sistem

Buat Akun Pengguna (Hanya Lihat)

Buat akun tambahan untuk panitia yang hanya perlu melihat data — akun ini tidak memiliki hak untuk menambah, mengubah, menghapus, mengimpor data, atau mengedit berita acara apa pun di sistem ini.

Akun ini terdaftar di Firebase Authentication dan bisa masuk lewat halaman login menggunakan ID & kata sandi di atas. Viewer hanya dapat melihat Dashboard, Data Masyarakat, serta Berita Acara (termasuk cetak/unduh dokumen). Hak tulis juga dibatasi oleh Firebase Security Rules, bukan hanya oleh tampilan halaman.

Ganti Kata Sandi

Perbarui kata sandi akun Anda secara berkala untuk menjaga keamanan data.
